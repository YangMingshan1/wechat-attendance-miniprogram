### 关键断言说明

**距离计算**（决定"超出阈值禁止签到"是否准确）

| 断言 | 期望 | 说明 |
|---|---|---|
| 同一点距离 | `0` 米 | 边界情况 |
| 纬度差 1 度 | 111195 米 ± 100 | 对应子午线弧长 |
| 北纬 60 度经度差 1 度 | 55600 米 ± 200 | 验证 `cos(纬度)` 因子生效 |
| 赤道经度差 1 度 | 111195 米 ± 1 | 球面模型理论值 `R×π/180` |
| 约 13 米近距离 | 13.34 米 ± 0.5 | 典型签到场景精度 |
| 约 311 米远距离 | 311.3 米 ± 2 | 超范围场景 |
| 球面 vs 椭球模型差异 | < 0.1 米 | 验证模型简化的精度足够 |
| 距离计算对称性 | 完全一致 | `d(A,B) == d(B,A)` |

**坐标校验**（防止非法定位数据入库）

覆盖：合法值、纬度越界、经度越界、`(0,0)` 异常值、字符串、`NaN`、`undefined`、边界值 `90/180`。

**Excel 表头识别**（决定导入功能是否好用）

覆盖：标准中文表头、列顺序打乱、含多余列、英文表头、大小写与空格容错、全角空格容错、缺列时返回 -1、无关行不误判。

**唯一键冲突识别**（决定并发去重能否生效）

覆盖：`duplicate key`、`E11000`、中文"已存在"、错误码 `-501001`、普通错误不误判、`null` 安全。

> 该校验直接决定"无例外"约束在并发场景下是否成立，因此单独做了 6 项断言。

**分页与时间**

- 分页：缺省值、正常翻页、负数页码纠正、超大 pageSize 截断为 100、非法值回退
- 时间：UTC → 北京时间换算、跨日进位、批次号格式、无效输入返回空串
