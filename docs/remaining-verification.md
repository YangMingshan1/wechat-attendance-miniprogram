### P0-2 签到：超范围拦截（任务书硬性要求）

**操作**：把坐标偏移约 0.01 度（≈1.1 公里），再调一次：

```js
wx.cloud.callFunction({
  name: 'signIn',
  data: {
    courseId: '你的课程ID',
    sno: '20230101002',        // 换个学号，避免撞上去重
    name: '王小红',
    deviceId: 'test-device-002',  // 必须换个设备 ID，否则会先去重拦截
    latitude: 30.522400,   // 纬度 +0.01 度 ≈ 偏离 1.1 公里
    longitude: 114.365400
  }
}).then(r => console.log(r.result))
```

**预期**：

```json
{ "code": 410, "msg": "当前位置距离签到点位 xxx 米，超出允许范围 50 米", "data": { "status": "OUT_OF_RANGE", "distance": 1111.95, "radius": 50 } }
```

**关键判定**：返回 `410`，且**不写入** `records` 集合（记录数不变）。

- [ ] 通过

### P0-4 并发去重（唯一索引是否真的生效）★ 最重要

**为什么最重要**：这是"无例外"的真正兑现点。仅靠"先查再写"在并发下会失效，只有数据库唯一索引能挡住。

**操作**：挑一个**还没签到的课程+设备组合**，同时发两次请求：

```js
const payload = {
  courseId: '一个还没签到的课程ID',
  sno: '20230101003',
  name: '赵小刚',
  deviceId: 'test-device-concurrent',   // 全新设备 ID
  latitude: 30.512400,
  longitude: 114.365400
};
Promise.all([
  wx.cloud.callFunction({ name: 'signIn', data: payload }),
  wx.cloud.callFunction({ name: 'signIn', data: payload })
]).then(rs => console.log(rs.map(r => r.result)))
```

**预期**：

- 一个返回 `code: 0`，一个返回 `code: 411`
- `records` 集合中该 `courseId + deviceId` **只有 1 条**

**如果出现 2 条** → `records` 的 `uk_course_device` 唯一索引没建上，回控制台检查索引。

- [ ] 通过

## 注意事项

**测试数据清理**：测完后 `records` 里会有测试记录，`users` 里会有测试学生。如果要重新开始，去控制台清空这两个集合即可（注意别删集合本身，只删记录）。

**deviceId 的作用**：`signIn` 的去重键是 `courseId + deviceId`。手工测云函数时**每次换一个 deviceId** 才能测不同的场景，否则第二次就被"已签到"拦住了。

**改代码后要重新上传云函数**，尤其是改 `cloudfunctions/_common/` 下的文件——那些是复制分发的，必须先执行：

```bash
node scripts/sync-common.js
```

再逐个重新上传受影响的云函数。
